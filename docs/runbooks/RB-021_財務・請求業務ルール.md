# RB-021 財務・請求業務ルール

## 1. 目的

BA-016として、適格請求書、消費税率、端数処理、源泉徴収、訂正、会計マッピングの運用ルールを固定する。

## 2. 適格請求書

- 適格請求書に対応する。
- 登録番号等の実値は環境設定または業務マスタで管理し、GitHubへ実値を保存しない。
- 適格請求書に記載する消費税額等は、1請求書につき税率ごとに1回だけ端数処理する。
- 商品・明細ごとに端数処理した税額の合計を請求書税額として扱わない。

参考: 国税庁「適格請求書に記載する消費税額等の端数処理」
https://www.nta.go.jp/taxes/shiraberu/zeimokubetsu/shohi/keigenzeiritsu/pdf/qa/57.pdf

## 3. 消費税率と端数

- 標準税率 10% を基本とする。
- 軽減税率 8% もデータモデル上は扱えるようにする。
- 端数処理方式の社内標準は切捨てとする。
- 税率は請求書明細へ明示的に保持し、将来変更可能な設定値として扱う。
- 税率ごとの課税対象額を集計後、その税率について1回だけ端数処理する。

## 4. 源泉徴収

- 対象／対象外を取引先または請求単位で明示設定できること。
- デフォルトは対象外とする。
- 業種名、案件名、自由記述だけから自動的に対象判定しない。
- 対象判定には支払先属性・報酬等の種類などの確認が必要なため、業務責任者が確定する。
- システムは設定済み結果を計算へ反映する。

参考: 国税庁「源泉徴収が必要な報酬・料金等」
https://www.nta.go.jp/taxes/shiraberu/taxanswer/gensen/2792.htm

## 5. 請求書訂正

- 確定済み請求書を直接上書きしない。
- 訂正時は元請求書との関連を保持した訂正版、取消、再発行等の履歴を残す。
- 元データ、訂正理由、訂正者、訂正日時を監査可能にする。
- 発行済み番号の再利用は禁止する。

## 6. 会計マッピング

- 勘定科目コード、補助科目、部門コード、税区分コード等は現時点で特定会計ソフトへ固定しない。
- 外部会計連携時に設定可能なマッピングテーブルで対応する。
- 会計マッピング変更は過去請求書の確定値を遡及変更しない。

## 7. Production条件

Production利用前に次を確認する。

1. 適格請求書の必須項目マッピング確認
2. 10%・8%双方の税計算テスト
3. 税率別1回の端数処理テスト
4. 切捨て結果の境界値テスト
5. 源泉徴収の対象／対象外設定テスト
6. 確定済み請求書の直接更新拒否
7. 訂正・取消・再発行履歴の追跡
8. 会計マッピング変更が過去確定値へ影響しないこと

## 8. 完了条件

BA-016の実装完了は、ポリシー・CIガードの導入までとする。正式な業務完了には、実際の請求書様式・取引類型での業務レビューとStaging検証が必要である。
