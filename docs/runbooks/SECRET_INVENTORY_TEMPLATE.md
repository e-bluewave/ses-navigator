# Secret台帳テンプレート

このファイルには秘密値を記録しない。環境ごとの正式台帳は、アクセス制御された運用管理場所へ複製して使用する。

## 記入ルール

- Secret IDは値と無関係な名称にする。
- API key、JWT、password、token、credential、秘密値の断片を記載しない。
- 保管先はサービス名と登録区分までとし、秘密値を直接取得できるURLや共有リンクを記載しない。
- Production、Staging、CI、Localを別行で管理する。
- ローテーションまたは失効後は状態と日付を更新する。
- リポジトリへ保存するのは空のテンプレートだけとする。
